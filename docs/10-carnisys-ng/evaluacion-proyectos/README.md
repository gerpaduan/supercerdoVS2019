## Criterio de uso

Cada ficha debe completarse con evidencia del codigo actual y una recomendacion conservadora.

La decision final no debe basarse en preferencia tecnica sino en:

- valor funcional
- riesgo operativo
- compatibilidad con la arquitectura NG
- esfuerzo de aislamiento
- impacto en la migracion
