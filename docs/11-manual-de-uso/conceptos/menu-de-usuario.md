# Menú de usuario

Tocá tu nombre (arriba a la derecha) para abrirlo. Algunas opciones aparecen solo si corresponden.

| Opción | Para qué sirve | Quién la ve |
|---|---|---|
| **Sucursal actual** | Muestra en qué sucursal estás operando; al tocarla podés **cambiarla**. El cambio queda guardado en tu usuario (no es solo de esta sesión). | Todos |
| **Número de serie** | Muestra el identificador de **esta PC** (solo si el agente de impresión de CarniSys está instalado y corriendo) y un botón *Copiar*. Se lo pasás a un administrador para que autorice la PC en *Dispositivos seguros*. | Todos |
| **Mi jornada** | Tu fichaje de entrada y salida. Para un usuario de producción, primero elige quién es. | Solo si sos usuario de producción o tenés un empleado asociado |
| **Mi huella** | Registrar la huella (o PIN/rostro del equipo o celular) para ingresar sin escribir usuario ni contraseña. | Solo si la huella está habilitada en el servidor |
| **Clave rápida (PIN)** | Configurar o quitar tu [PIN](ayuda:concepto/clave-rapida-pin). | Solo no administradores |
| **Manual de uso** | Abre esta ayuda (sin sacarte de la pantalla). | Todos |
| **Cambiar clave** | [Cambiar tu contraseña](ayuda:pantalla/Login.ChangePassword). | Todos |
| **Cerrar sesión** | Sale del sistema. | Todos |

Junto al nombre está el botón **?** (**Ayuda**): abre un panel con el manual de la pantalla en la que estás, **encima** de ella: no te saca de lo que estás haciendo.
