# Buscar cliente, vendedor o proveedor en los filtros

Los filtros **Cliente**, **Vendedor** y **Proveedor** de [Ventas](ayuda:pantalla/Ventas.Index), [Facturas](ayuda:pantalla/Ventas.Facturas), [Líneas de venta](ayuda:pantalla/Ventas.Lineas), [Compras](ayuda:pantalla/Compras.Index) y [Líneas de compra](ayuda:pantalla/Compras.Lineas) se pueden usar de **dos maneras**.

## 1. Escribir (como siempre)
Escribís parte del nombre y la pantalla muestra todo lo que **contenga esas letras** (en cliente también la identificación). Sirve para una búsqueda rápida, pero puede traer personas parecidas.

## 2. Elegir de la lista (filtra exacto)
1. Tocá la **lupa** del campo, o usá el atajo del teclado: **F9 = vendedor** (y proveedor en Compras), **F10 = cliente**.
2. Se abre una ventana con la lista. Escribí arriba para acotarla.
3. **Tildá** los que querés ver: podés elegir **varios**. Lo que tildás queda arriba como etiquetas (con una ✕ para quitarlas), aunque cambies la búsqueda.
4. Tocá **Aplicar**.

Con la selección hecha:
- El campo queda **bloqueado** (no se puede escribir) y muestra el nombre, o *"3 clientes seleccionados"* si elegiste varios. Con el mouse encima se ve la lista completa.
- Debajo, en letra chica, se ve la **identificación** (solo si es distinta de la razón social) o, si elegiste varios, sus nombres.
- El filtro es **exacto**: trae solo lo de **esas** personas, no las que se parecen.
- Para volver a escribir, tocá la **✕** del campo: la selección se borra, el campo se habilita y vuelve a buscar por letras.

## Teclado dentro de la ventana
| Tecla | Qué hace |
|---|---|
| **Enter** | Tilda o destilda la fila marcada. |
| **↑ ↓** | Mueven la fila marcada. |
| **Alt + número (1 a 9)** | Tilda esa fila de la lista. |
| **Alt + Enter** | Aplica la selección. |
| **Esc** | Cierra sin cambiar nada. |

La barra espaciadora **no** tilda: se usa para escribir varias palabras en la búsqueda.

## Notas
- En la lista de **vendedores** aparecen primero los usuarios activos y después los dados de baja (marcados *inactivo*), porque tienen ventas de antes.
- La lista muestra hasta **200** resultados; si hay más aparece un aviso para que escribas más letras.
- Un candado junto al nombre indica un cliente con **cuenta corriente reservada**.
- Hasta **500** personas en una misma selección.
