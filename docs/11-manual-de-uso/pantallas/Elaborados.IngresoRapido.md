## Para qué sirve
Elegir el producto que vas a registrar con **Ingreso rápido** o a desarmar con **Desarme de elaborado**. Es la misma pantalla para los dos; cambia la etiqueta (*Modo ingreso rapido* / *Modo desarme*) y el color del botón. Al tocar **Seleccionar** se abre la carga de ese producto (ver [Ingreso rápido y desarme de elaborado](Elaborados.EditarIngresoRapido.md)).

## Buscar
El cuadro *Producto o codigo* filtra la lista mientras escribís, por nombre o por código. Si nada coincide aparece *No hay productos que coincidan con el filtro actual*. Doble clic sobre un producto equivale a **Seleccionar**.

## En el celular
Cada producto se muestra como una **tarjeta**: arriba el nombre con el código en gris a la derecha (y la receta debajo, si tiene), después *Ingreso rápido* (Sí/No) y *Fórmula* en dos columnas, y el botón **Seleccionar** a todo el ancho. En la computadora sigue la tabla de siempre.
