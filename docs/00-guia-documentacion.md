# Guia de uso de esta documentacion

## Objetivo

Ordenar el relevamiento de CarniSys para que sea facil ubicar procesos, pantallas, reglas y puntos sensibles del sistema.

## Como completar cada seccion

- Describir que hace el modulo o flujo.
- Indicar formularios, vistas, clases o proyectos involucrados.
- Detallar entradas, validaciones y resultados.
- Registrar dependencias externas si existen.
- Anotar dudas y riesgos por separado.

## Convenciones sugeridas

### Estado

- `Confirmado`: validado en codigo o en uso actual.
- `Pendiente`: falta revisar o probar.
- `Riesgo`: cambio sensible o con impacto en produccion.

### Estructura recomendada

1. Objetivo
2. Pantallas o componentes
3. Flujo principal
4. Validaciones
5. Dependencias
6. Observaciones
